# .planning/

GSD (Get Shit Done) planning vault for this repo. Captured ideas, notes, and
todos live here, following the conventions defined in `.claude/gsd-core/`.

## Layout

- `notes/` — project-scope notes: durable, timestamped context snapshots
  (`{YYYY-MM-DD}-{slug}.md`). This is where synced external lists and
  quick-capture context live.
- `todos/pending/`, `todos/completed/` — structured, one-per-file todos
  (created as work is triaged; not yet populated).
