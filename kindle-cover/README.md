# Kindle sleep-screen cover (KOReader)

Pick the PNG that matches your Kindle's screen:

| File | Kindle |
|---|---|
| `paperwhite-11th-gen_1236x1648.png` | Paperwhite 5 / Signature (11th gen, 2021) |
| `oasis-colorsoft-paperwhite12_1264x1680.png` | Oasis 2/3, Colorsoft, Paperwhite 12th gen (2024) |
| `paperwhite-basic-1072x1448.png` | Paperwhite 3/4, Voyage, Basic 2022 (11th gen) |
| `scribe_1860x2480.png` | Kindle Scribe |
| `basic-touch-600x800.png` | Older basic Kindles / Touch |

## Install
1. Plug the Kindle into a computer over USB.
2. Copy the PNG to `koreader/screensaver/` (create the folder if needed).
3. On the Kindle in KOReader: **Settings (gear) → Screen → Sleep screen → Wallpaper → Show custom image or cover** then **Choose image or document → pick the PNG**.
   (Older KOReader: *Screen → Screensaver → Use custom image as screensaver → Choose screensaver image*.)
4. Turn off "Show book cover" / "message" options if you only want the photo.
5. Lock the Kindle to see it.

If the stock Amazon lockscreen still shows ads/cover instead, KOReader only controls sleep while KOReader is running; exit to KOReader (not the Kindle home UI) before sleeping, or install the **linkss** / screensaver hack for the native UI.
